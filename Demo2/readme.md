The Demo2.Ino File contains all of our Arduino code. It contains a statemachine with 4 states that we used to control it. The states are SEEK, ZEROING, DRIVING, TURNING.
they all do what the name states. The zeroing state however also reads in the new data from the camera. The functions folder contains our receive function which is where we get the information from the camera. It uses code from the mini project but changes it a little to receieve a new amount of bytes from the PI. The functions foulder also uses pointers to convert binary to floats and other numbers. We then call it during every loop iteration in the Demo2.ino file.
